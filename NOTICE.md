# Credits and licensing status

CHIM Sealed Fates is an independent extension for CHIM. It targets documented CHIM and HerikaServer interfaces and references the CHIM/AIAgent, SKSE, JContainers, and Papyrus Extender (PO3) APIs. Their names and software remain with their respective maintainers; this project does not imply endorsement.

The install packages do not bundle those projects' SDK packages. Obtain and use CHIM and its dependencies under the terms supplied by their maintainers.

No project LICENSE or COPYING file existed in the development snapshot; none was added here. Dependency credits do not assign a project license.
