# Sealed Fates artwork

The selected 1536 × 1024 original is [dashboard-art-source.png](../assets/dashboard-art-source.png). The web page uses [dashboard-art.webp](../server/dashboard-art.webp), a lossless WebP encoding whose decoded pixels match the original exactly.

The illustration was generated for Sealed Fates with the built-in image-generation tool, then edited to restore the recurring emo llama: black side-swept fringe, unimpressed expression and red scarf. It follows the sibling plugins with aged parchment, carved black woodcut marks, muted blue mountains, rust-red cloth and a small llama cameo. The courier carries letters past two contrasting reactions: affection and outrage.

The complete image remains visible on the web page rather than being cropped into a banner. The PNG is retained for future artwork work; the WebP ships in the server package. Neither contains functional game state or configuration.
